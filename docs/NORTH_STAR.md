# MELHORIAS SOLICITADAS

## 1.

Criar um novo capítulo:

# Anti Goals

Responder claramente:

O ParaguAI NÃO existe para:

* maximizar pageviews;
* aumentar tempo de permanência artificialmente;
* copiar funcionalidades de concorrentes;
* adicionar recursos sem resolver problemas reais;
* aumentar complexidade sem benefício;
* privilegiar anunciantes sobre relevância;
* manipular rankings por interesse comercial;
* criar dependência da IA quando transparência for mais importante;
* construir funcionalidades apenas porque são tecnicamente interessantes.

Explicar o motivo de cada item.

---

## 2.

Criar um capítulo:

# Tipos de Decisão

Inspirado no conceito de decisões Tipo 1 e Tipo 2.

Definir:

Tipo 1

Difíceis de reverter.

Exemplos:

* domínio
* arquitetura
* modelo de dados
* identidade
* princípios
* estratégia

Necessitam análise profunda.

Tipo 2

Facilmente reversíveis.

Exemplos:

* layout
* textos
* ordem de menus
* componentes
* UX
* pequenos fluxos

Devem ser decididas rapidamente.

O objetivo é acelerar decisões sem comprometer o futuro.

---

## 3.

Criar um princípio permanente:

# Compounding Decisions

Explicar que:

Toda Release deverá deixar ativos que tornem a próxima Release mais fácil.

Nunca construir apenas funcionalidades.

Sempre construir plataformas reutilizáveis.

Sempre deixar o projeto mais inteligente do que antes.

---

## 4.

Fortalecer o capítulo de longo prazo.

Adicionar explicitamente:

"Sempre preferimos construir infraestrutura reutilizável em vez de soluções específicas."

Explicar por quê.

---

## 5.

Adicionar um fechamento.

Criar uma seção final chamada:

# O Compromisso

Explicar que:

Toda decisão tomada hoje deverá facilitar decisões futuras.

Toda Release deverá diminuir a complexidade da próxima.

Toda arquitetura deverá aumentar a capacidade de evolução.

Nunca resolver apenas o problema atual.

Sempre preparar o próximo estágio do ParaguAI.
